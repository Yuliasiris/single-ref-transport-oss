# Source and attribution boundary

This clean source tree is a standalone component extracted from private development.
The earlier private Git history is intentionally not part of the public history.
A separate private audit retains the mapping to the original source identity.

The rights holder confirmed authority to publish this selected code and documentation
under the MIT License. The scoped audit found no existing third-party copyright,
license, COPYING, or NOTICE file in the selected source. This is not a claim that
future provenance information can never require an additional notice; newly identified
upstream attribution must be preserved.

The runtime bundles no third-party runtime library. Python, Git, Node.js, TypeScript,
and GitHub Actions are separately installed tools and are not redistributed as part
of the runtime package. Examples use synthetic values, not private repositories,
credentials, transcripts, creative works, or a private corpus.

The public-facing documentation and packaging were prepared for the clean release
tree. See LICENSE for the granted permissions.
